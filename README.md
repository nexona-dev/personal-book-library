# 📚 Personal Book Library

**A Professional Excel-Based Book Collection, Reading Tracker & Personal Library Management System**

Personal Book Library is a comprehensive Excel-based system designed to help readers organize their book collections, track reading progress, manage authors and publishers, record notes and quotations, and analyze their reading habits.

It combines personal library management, bibliographic organization, reading analytics, and collection tracking in one structured workbook.

---

## ✨ Features

### 📖 Book Collection Management
- Organize books in a centralized catalog.
- Store original titles and publication information.
- Track physical books, digital books, audiobooks, and wishlist items.
- Record ISBN-13 numbers.
- Manage multiple editions of the same literary work.
- Track book condition and physical shelf location.
- Store book cover and reference links.

### ✍️ Authors & Contributors
- Maintain detailed author profiles.
- Store author biographies and country of origin.
- Track translators, editors, and other contributors.
- Link multiple authors to the same work.
- Explore books associated with each author.

### 🏢 Publishers & Editions
- Maintain a dedicated publisher database.
- Track publication years and edition numbers.
- Record ISBNs, page counts, languages, and formats.
- Compare different editions of the same work.
- Organize translated editions and contributors.

### 📚 Reading Progress
- Track currently reading, completed, planned, and abandoned books.
- Record the last read page or listening position.
- Calculate reading progress automatically.
- Maintain reading history.
- Track repeated readings.
- Record start and completion dates.

### 📊 Reading Analytics
- Monitor total books and completed books.
- Analyze total pages read.
- Track reading hours and sessions.
- Review reading statistics and performance.
- Analyze favorite authors, publishers, and genres.
- Visualize personal reading progress through charts.

### 💬 Quotes & Personal Notes
- Save favorite quotations.
- Record page numbers or timestamps.
- Add personal interpretations and comments.
- Organize quotations by themes and tags.

### 💰 Book Purchases & Budget
- Record purchase dates and sellers.
- Track original prices, discounts, shipping costs, and net expenses.
- Manage multiple currencies separately.
- Monitor book collection spending.

### 📚 Series Management
- Organize books into literary series.
- Track reading order.
- Identify missing books.
- Monitor series completion.

### 🔄 Additional Management Tools
- Personal reading goals.
- Book reviews and ratings.
- Borrowed and lent book tracking.
- Reading plans and priorities.
- Custom categories and tags.
- Shelf and collection organization.

## 📂 Workbook Structure

The workbook includes dedicated worksheets for:

| Worksheet | Purpose |
|---|---|
| Dashboard | Main library overview and statistics |
| Works | Main literary works catalog |
| Authors | Author database |
| Publishers | Publisher database |
| Contributors | Translators, editors, and other contributors |
| Editions | ISBN and edition information |
| Copies | Owned and wanted book records |
| Series | Book series management |
| Reading Status | Current reading progress |
| Reading Log | Daily reading sessions |
| Quotes | Favorite quotations and notes |
| Reviews | Book ratings and evaluations |
| Purchases | Purchase history and expenses |
| Loans | Borrowing and lending records |
| Goals | Reading goals |
| Statistics | Library analytics |
| Settings | Categories and configurable options |

*The workbook currently uses Turkish worksheet labels and data-entry fields. The repository documentation is in English.*

---

## 🚀 Getting Started

1. Download `Personal_Book_Library.xlsx` from this repository.
2. Open the workbook using Microsoft Excel.
3. Start with the usage guide on the first worksheet.
4. Add authors and publishers.
5. Register literary works and their editions.
6. Add your physical, digital, or audio copies.
7. Start tracking your reading progress.
8. Use the Dashboard and Statistics worksheets to analyze your activity.

## 🛠️ Requirements

- Microsoft Excel 365 or a compatible modern Excel version.
- Basic spreadsheet knowledge.
- No additional software installation is required for normal workbook usage.

---

## 🔒 Privacy & Data Ownership

This project is designed for personal use.

Your book records, reading history, quotations, reviews, and purchase information remain in your own workbook.

The repository is intended to store and maintain project versions. Do not upload private reading notes or personal records to a public repository.
